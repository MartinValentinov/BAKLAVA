THE LOADING ANIMATION
=====================

loading.svg in this folder is the one the app uses. It is the BAKLAVA mark
being rubbed out and drawn back in, on a loop.

WHERE IT COMES FROM
    It is assembled from the eight drawings in static/img/frame_*.svg:

        frame_0_8  the finished mark        (also used as the logo)
        frame_1    ...
        frame_2    ...rubbed out
        frame_3    ...
        frame_4    empty
        frame_5    ...
        frame_6    ...drawn back in
        frame_7    ...

    and then loops back to frame_0_8. Everything that makes it move sits in
    the <style> block at the top of loading.svg, so it is a picture that
    animates itself: no JavaScript, and no separate frame files to load.

IF YOU CHANGE A FRAME
    loading.svg is assembled, not drawn - do not edit it by hand. Redraw the
    frame in static/img/ and then run, from the project folder:

        python static/anim/build_loading_animation.py

    That rewrites loading.svg. Nothing else has to change.

TO CHANGE THE SPEED
    FRAME_MS at the top of build_loading_animation.py is how long one frame
    stays on screen (150 milliseconds). Change it and run the script again.

TO USE A DIFFERENT ANIMATION
    Drop the file in this folder (a .gif or an animated .svg both work) and
    point "loading_animation_path" in app.py at it, e.g.

        "loading_animation_path": "anim/loading.gif",

    Its size on screen comes from --loader-size in static/css/style.css.
